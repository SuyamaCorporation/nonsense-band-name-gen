## ナンセンスバンド名ジェネレータ

「形容詞＋奇妙な名詞」の組み合わせでインディー・メタル・アイドル・クラシック系の架空バンド名をランダム生成し、架空のアルバムジャケット情報（アルバム名・曲目・レーベル）をテキスト表示するエンタメツール。

### 機能
- 4ジャンル（インディー/メタル/アイドル/クラシック）切り替え
- バンド名・アルバム名・レーベル・曲目リストのランダム生成
- 生成結果のlocalStorage保存（最大20件）
- 保存履歴一覧表示・消去機能

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- localStorage永続化
